# rdaaraujo.com

Site pessoal e portfólio de Rafael Araujo, desenvolvedor back-end.

Feito com Next.js, TypeScript e Tailwind CSS. Publicado na Vercel.

## Rodando localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Editando o conteúdo

Textos, links, experiência, projetos e skills ficam em `src/data/site.ts`. Para mostrar uma foto no topo, coloque o arquivo em `public/` e preencha `photo` nesse arquivo.

## Estrutura

- `src/app`: layout e página principal
- `src/components`: seções do site
- `src/data/site.ts`: conteúdo
